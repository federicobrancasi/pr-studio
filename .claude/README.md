# The skills and the reviewer

- [`skills/pr-video/`](skills/pr-video/SKILL.md): the `pr-video` skill, its guides and the diagram catalog.
- [`skills/presentation/`](skills/presentation/SKILL.md): the `presentation` skill (slide decks in the same look), its
  guides and the layout samples.
- [`agents/pr-director.md`](agents/pr-director.md): the `pr-director` agent, which reviews a video and signs it off.

GitHub Copilot (VS Code and the Copilot CLI) and Claude Code load them from this folder, so there is nothing to
set up: open the repo and ask for a video of a pull request, or for a presentation.
